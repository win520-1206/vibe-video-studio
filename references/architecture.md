# 架构：复用制作管线，每题重新设计镜头

用户约定与科学来源 → 原稿与镜头动作 → 主题模型/场景状态 → 项目专属视图 → Remotion合成。音乐 → 预计算特征与事件 → 状态响应、文字强调、混音。实际导出 → 技术检查与人工观看/审听。

保留的是时间、配置、分析和交付机制，不保留上一作品的视觉场景。shared/scene-registry.mjs注册可独立计算的state；src/scenes.tsx注册同名视图。React处理精确中文；SVG/Canvas处理图解；WebGL处理空间与大量对象；Blender按需离线制作。各层共享一个音乐与事件时钟。

state是帧、模型、种子和预计算特征的函数。需要积分的模拟先缓存固定步长结果，禁止依赖上一渲染帧、Date.now或非固定随机数。模型与视觉映射分开，绘图不能改样本量、概率或物理条件。对象ID、世界坐标、投影坐标、保护区域与关键统计用于检查，不把镜头平移算作科学对象变化。

不同题材的对象、尺度、转场与运动语法需要重新设计，具体接口见[脚手架](scaffold.md)，构思方法见[主题设计](theme-led-design.md)。没有默认动画核心或可套用的球体组件。历史作品使用自己的工程；新底座不会修改它们。
