# 科学依据与类比边界

模型：均匀理想线性、无色散介质。两个相反位移的高斯脉冲分别以相反恒速传播，y(x,t)=y1(x,t)+y2(x,t)。标记点表示介质位置的位移，不是沿波速迁移的物质。完全相遇时位移为零，不代表能量消失；本片不绘制能量密度或模拟真实水波。

依据：[OpenStax University Physics 16.5](https://openstax.org/books/university-physics-volume-1/pages/16-5-interference-of-waves)。模型公式为本工程解析构造。

最后一句是作者对“当下现象并非整个过程”的感悟，不是利用波动方程证明人际关系。
