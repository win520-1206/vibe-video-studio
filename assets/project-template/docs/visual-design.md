# 本作品视觉与情绪设计

先确定主题、受众和希望传达的思考。记录对象、科学机制与适用条件、开场疑问、观众原先理解与认识转变、情绪来源、结尾回应，以及事实/模型/类比/观点边界。知识、动画与情绪在同一作品中推进，不分模式，不规定比例或段落时长。

再确定尺度、镜头、排版、材质、配色、音乐情绪及与可访问旧作的区别。每镜写初态—条件—动作—结果—理解变化—感受变化—依据—声音事件—接续—实现路线。不要让背景装饰替代主体动作。

ID确定后用plan:shots生成creative-plan.json，填写后用check:creative核查和刷新qa阅读版。配置是时间、原稿和音乐事件的唯一来源。完整确认稿、稳定阅读和对象可读性必须保留。
